# 标注锚点（ANNOTATION）

这套数字是系统精度的上限，标注不一致会让评分失去意义。

每个轴提供 0.2 / 0.5 / 0.8 三档锚点，标注活动时以此为参照。0.2 = 低端，0.5 = 中位，0.8 = 高端。

## 活动维度（D 轴 + focusNeedMin）

| 轴 | 0.2 | 0.5 | 0.8 |
|---|---|---|---|
| D1 认知强度 | 跟着做就会 | 需要理解几个新概念 | 概念密集需反复推演 |
| D2 知识门槛 | 零基础可上手 | 需要一点同类经验 | 必须先掌握前置知识 |
| D4 结构化需求 | 随便怎么开始都行 | 有个大概流程 | 必须按固定步骤否则会崩 |
| D5 产出压力 | 没有明确终点 | 有松散的产出目标 | 必须交付成果并被检验 |
| D7 反馈即时性 | 几千小时后才知道对错 | 当天或当周有反馈 | 做错的下一秒就知道 |
| focusNeedMin 专注时间 | 15分钟够 | 30-45分钟 | 需要60分钟以上 |
| D6 社交需求 | 完全自己来 | 偶尔交流 | 必须团队协作 |

## 画像维度（person 轴）

| 轴 | 0.2 | 0.5 | 0.8 |
|---|---|---|---|
| E 经验 | 从未接触 | 跟着教程做过 | 熟练并能教别人 |
| I 兴趣 | 完全不想碰 | 还行可以学 | 非常想学 |
| structureNeed 结构需求 | 自由探索 | 有大方向 | 需要明确步骤 |
| openLoop 开放循环 | 无所谓 | 有点惦记 | 必须做完 |
| socialPref 社交偏好 | 独自最好 | 偶尔交流 | 必须有人一起 |
| recovery 恢复 | 经常熬夜 | 一般 | 规律充足 |
| block 专注块 | ≤20分钟 | 45分钟左右 | >90分钟 |
| stuck 卡住反应 | 自己查 | 问人 | 换别的做 |
| peakTime 清醒时段 | 早晨 | 下午 | 深夜 |

## 标注规则

1. **三档锚点是校准标尺，不是刻度**：0.2 / 0.5 / 0.8 之间允许填 0.3、0.7 等中间值，但必须能在脑中对上锚点描述。
2. **D1 与 D2 容易混淆**：D1 是"这事本身多烧脑"，D2 是"做之前你要会多少"。D1=0.8 但 D2=0.2 是合法的（认知密集但零基础可上）。
3. **D4 vs structureNeed**：D4 是活动自身的结构化需求（步骤刚性），structureNeed 是个人对结构的依赖。两者独立标注。
4. **D6 vs socialPref**：D6 是活动对协作的要求，socialPref 是个人偏好。都学钢琴 D6≈0.05，但 socialPref 可因人而异。
5. **E 与 I 独立**：经验高不代表兴趣高（老手可能倦怠），兴趣高不代表经验高（小白可能很想去学）。
6. **stuck / peakTime 为枚举值**：stuck ∈ {search, ask, switch}，peakTime ∈ {morning, forenoon, afternoon, evening, night}。上表锚点仅为语义参照，实际存储为字符串。
7. **recovery 与 weeklyHours 不进评分公式**：recovery/weeklyHours 用于 `weeklyCapacity`（周容量），不参与 `scoreActivity` 的分项计算，但字段使用断言会检查是否被读取。
