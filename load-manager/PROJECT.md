# 学习配速器 · 项目介绍

> 把学习挑战调到刚好——一个帮你找到"不太难也不太简单"学习节奏的小工具。

## 这是什么

**学习配速器**是一个纯网页应用，帮你回答一个问题：**"这件事对我来说，难度合适吗？"**

你填一份简单的问卷（5 分钟），它会生成一份专属于你的学习画像，然后告诉你每个学习活动对你来说是太简单、刚刚好、还是太吃力。

## 能帮你做什么

| 功能 | 说明 |
|------|------|
| 📝 **学习画像** | 回答几个问题，系统用大白话告诉你：你适合怎么学、什么时候学、学多久最合适 |
| 🎯 **活动匹配度** | 12 个学习活动按"和你的匹配程度"上色——绿色=很适合，红色=可能太吃力 |
| 📋 **三套推荐计划** | 给你准备了三套不同节奏的学习方案：轻松起步 / 高效甜区 / 挑战突破，选一个就行 |
| 📊 **周负荷看板** | 看看你这周安排的学习量会不会超载，环形进度条一目了然 |
| 🔄 **持续校准** | 每次学完反馈真实感受，系统会越来越懂你 |

## 为什么用它

- **零门槛**：不用装软件、不用注册账号，双击 `index.html` 就能用
- **完全离线**：所有数据存在你自己的浏览器里，不上传任何服务器
- **大白话**：没有专业术语，普通人也能看懂
- **不替你决定**：它只告诉你"这件事可能有点难"，做不做还是你说了算

## 快速开始

1. 双击 `index.html`，在浏览器中打开
2. 点击「开始问卷」，回答 6 个问题（全部必填）
3. 查看你的学习画像，然后去「活动库」挑感兴趣的活动
4. 选一套推荐计划，或者自己搭配，加入本周计划
5. 学完后反馈感受，系统会自动校准

> 也可以用本地服务器运行：在项目目录下执行 `python -m http.server 8765`，然后访问 `http://localhost:8765/`

## 技术特点（给开发者看）

- 纯原生 HTML + CSS + JavaScript，**零依赖、零构建、零 CDN**
- 评分引擎采用 **7 分量模型**（6 正向 + 1 负向），纯函数实现，浏览器和 Node 通用
- 所有 JS 挂在 `window.LMS` 命名空间，经典 `<script>` 标签加载
- 14 项自动化测试覆盖核心逻辑，可通过 `node tests/run.js` 运行

## 免责说明

这不是心理测量工具，而是一个**启发式的个性化提示工具**。分数基于你的自我报告，目的是帮你更好地感知自己的学习状态，而不是给出客观的"能力评分"。
