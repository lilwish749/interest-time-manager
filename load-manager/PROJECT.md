# 兴趣时间管理器 · 项目介绍

> 一个帮你管理兴趣、安排时间、分享成果的全能学习伙伴。

## 这是什么

**兴趣时间管理器**是一个纯网页应用，围绕你的兴趣展开，帮你解决四个问题：

1. **我有哪些兴趣？** → 兴趣池帮你随时记录、分类、管理
2. **这个兴趣对我来说难不难？** → 负荷管理系统给你个性化评判
3. **我该怎么安排时间学？** → 时间计划表自动帮你排好
4. **怎么秀给朋友看？** → 社交定制生成精美海报

## 四大核心功能

### 1️⃣ 兴趣池（首要功能）

随时随地记录你的灵感与兴趣，像一个"兴趣蓄水池"。

- **随手记录**：想到什么兴趣就记下来，不用想分类
- **AI 智能识别**：输入兴趣名称，AI 自动判断它属于哪个类别（编程、音乐、运动、语言……）
- **负荷联动评判**：识别后立即调用负荷管理系统，告诉你这个兴趣对你的负担等级（太轻松 / 刚刚好 / 有点难 / 会过载）
- **存取自由**：兴趣可以"存入"池中暂存，也可以"取出"开始学习，随时切换

> 示例：输入"学吉他"→ AI 识别为「音乐」类别 → 负荷系统判断为「最佳学习区」→ 可存入池或直接开始

### 2️⃣ 负荷管理系统

通过一份简单问卷生成你的专属学习画像，对每个兴趣活动进行个性化负荷评分。

- **7 分量评分模型**：从认知门槛、通道匹配、兴趣、时间、切换成本、产出压力、挑战不足 7 个维度综合评判
- **6 级负荷分区**：挑战不足 → 低负荷 → 舒适区 → 最佳学习区 → 高负荷 → 过载
- **匹配度可视化**：活动卡片按匹配度上色（绿=高度匹配，红=匹配偏低）
- **持续校准**：每次学完反馈真实感受，系统越来越懂你

> 详细技术说明见 [README.md](README.md)

### 3️⃣ 时间计划表

清晰的时间安排表格，帮你把兴趣落到每一天。

- **一键排程**：在兴趣池点「开始学习」，系统自动把计划填入时间表的空闲时段
- **智能避坑**：自动避开睡眠时间，不把活动排到凌晨
- **每日负荷等级**：表格上标注每天的总负荷，一眼看出哪天会超载
- **点击看详情**：点任意时间段查看活动详情、剩余时间、调整安排
- **简洁不单薄**：表格清爽易读，但信息密度足够——时间、活动、负荷、进度全都有

> 示例：想学吉他 → 系统生成完整学习计划（共 12 周，每天 1 小时）→ 一键排入你空闲的晚上 8-9 点 → 表格显示每天 1 小时吉他，负荷等级「适中」

### 4️⃣ 社交定制

把你的学习成果变成好看的海报，一键分享朋友圈。

- **自动生成海报**：综合你的兴趣、学习进度、负荷数据，生成精美海报
- **个性化排版**：配色、布局自动适配你的内容风格
- **一键导出**：保存图片，直接发朋友圈

## 完整使用流程

```
记录兴趣 → AI 识别分类 → 负荷评判 → 生成学习计划 → 一键排入时间表 → 每日执行反馈 → 生成社交海报
  兴趣池        兴趣池        负荷系统      兴趣池          时间计划表     负荷系统校准      社交定制
```

1. 在「兴趣池」输入你想学的东西
2. AI 自动识别类别，负荷系统告诉你难不难
3. 系统生成一套完整学习计划（多久、每天干什么）
4. 点「开始学习」，自动排进时间表空闲时段
5. 每天按计划学，学完反馈感受
6. 学得不错？生成海报分享朋友圈

## 为什么用它

- **一站式**：从记录兴趣到安排时间到分享成果，一个工具全搞定
- **零门槛**：不用装软件、不用注册，双击 `index.html` 就能用
- **完全离线**：所有数据存在你自己的浏览器里，不上传服务器
- **大白话**：没有专业术语，普通人也能看懂
- **智能排程**：不用自己算时间，系统帮你安排得明明白白

## 快速开始

1. 双击 `index.html`，在浏览器中打开
2. 先填一份问卷（生成你的学习画像，约 5 分钟）
3. 去「兴趣池」记录你的兴趣
4. 选择一个兴趣，查看负荷评判和学习计划
5. 点「开始学习」，自动排入时间表
6. 每天按计划执行，学完反馈
7. 生成海报分享

> 也可用本地服务器：`python -m http.server 8765` 后访问 `http://localhost:8765/`

## 技术特点（给开发者）

- 纯原生 HTML + CSS + JavaScript，**零依赖、零构建、零 CDN**
- 评分引擎采用 **7 分量模型**（6 正向 + 1 负向），纯函数实现，浏览器和 Node 通用
- 所有 JS 挂在 `window.LMS` 命名空间，经典 `<script>` 标签加载
- 14 项自动化测试覆盖核心逻辑，`node tests/run.js` 运行
- **开发要求**：每次提交前必须自行测试所有功能，确认真实可用
